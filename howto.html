HourCalendar — How to use

HourCalendar turns any monday.com board into a true hour-by-hour calendar. Setup takes under a minute.

1. Install and add the view

  1. Install HourCalendar from the monday.com marketplace (or via your installation link).
  2. Open any board, click the + next to your view tabs, choose Apps, and select HourCalendar.

2. One-minute setup

  1. Start column — pick the Date column that holds your start times (enable "time" on the column to schedule by the hour).
  2. Event end — choose how event length is determined:
    • Fixed duration (e.g. every event lasts 60 minutes),
    • End date column (a second Date column holds the end),
    • Duration column (a Numbers column holds minutes — resizing an event writes the new duration back).
  3. Show on event card — optionally display up to two columns (Status, Owner…) on each event.
  4. Subitems — tick to show dated subitems as events, labeled with their parent item.
  5. Click Save & open calendar.

3. Everyday use

  • ✨ AI Quick Add — type a phrase like Client call Thursday 3pm, 45 min in the top field and press Enter: the item is created at that exact slot.
  • Drag & drop — move an event to reschedule it; the real date and time are written back to your column instantly.
  • Resize — stretch an event to change its duration (End-column and Duration-column modes).
  • Unscheduled panel — items without a date wait on the left; drag one onto the calendar to schedule it.
  • Create from a slot — click any empty slot, type a name, pick a group — done.
  • Views — switch between Day, Week and Month; click an event for details or to open the full monday item card.
  • Settings — the ⚙ icon (top right) reopens the setup at any time.
Tip: if your board has no Date column yet, add one first (with "time" enabled) — the setup screen will guide you.
